b) Describe the data structures and reasons for their use

(a). Array / ArrayList

An ArrayList can store parking slots.

ArrayList<ParkingSlot> parkingSlots;

For example:

[A1, A2, A3, A4, A5, ...]

Each slot can contain:

1.Slot ID
2.Status 
3.Vehicle registration

Why use ArrayList?
1.Easy to add and remove records.
2.Easy to search.
3.Can dynamically grow.
3.Java provides built-in methods.

USE
-Store parking slots


(b). HashMap

A HashMap is particularly useful for finding a vehicle quickly using its registration number.

HashMap<String, ParkingRecord> parkedVehicles;

Example:

"KDA123A" → ParkingRecord
"KBC456B" → ParkingRecord
"KDD789C" → ParkingRecord

-The registration number becomes the key.

-This is better than searching through every vehicle one by one.

Advantage

Average lookup is approximately O(1).

So:

parkedVehicles.get("KDA123A");

can quickly retrieve the parking record.

USE
-Quickly find parked vehicles

(c). Queue

A Queue can optionally be used for vehicles waiting when the parking lot is full.

Queue<Vehicle> waitingVehicles;

Example:

Vehicle 1
   ↓
Vehicle 2
   ↓
Vehicle 3

-The first vehicle to join the queue gets the first available slot.

-This follows FIFO — First In, First Out.

USE
-Manage waiting vehicles

c)Design a dynamic database for the above scenario

Vehicle Table

Stores information about vehicles.



A.VEHICLE TABLE
| Field           | Data Type    | Description           |
| --------------- | ------------ | --------------------- |
| vehicle_id      | INT          | Primary key           |
| registration_no | VARCHAR(20)  | Vehicle registration  |
| vehicle_type    | VARCHAR(20)  | Car, motorcycle, etc. |
| owner_name      | VARCHAR(100) | Owner's name          |
| phone           | VARCHAR(20)  | Owner's phone         |

    SQL
CREATE TABLE vehicles (
    vehicle_id INT AUTO_INCREMENT PRIMARY KEY,
    registration_no VARCHAR(20) UNIQUE NOT NULL,
    vehicle_type VARCHAR(20) NOT NULL,
    owner_name VARCHAR(100),
    phone VARCHAR(20)
);




B. PARKING SLOT TABLE
| Field       | Data Type   | Description        |
| ----------- | ----------- | ------------------ |
| slot_id     | INT         | Primary key        |
| slot_number | VARCHAR(10) | Example A01        |
| status      | VARCHAR(20) | AVAILABLE/OCCUPIED |

 
SQL
CREATE TABLE parking_slots (
    slot_id INT AUTO_INCREMENT PRIMARY KEY,
    slot_number VARCHAR(10) UNIQUE NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'AVAILABLE'
);




C. PARKING RECORDS TABLE
| Field            | Data Type | Description      |
| ---------------- | --------- | ---------------- |
| record_id        | INT       | Primary key      |
| vehicle_id       | INT       | Vehicle          |
| slot_id          | INT       | Assigned slot    |
| entry_time       | DATETIME  | Entry time       |
| exit_time        | DATETIME  | Exit time        |
| duration_minutes | INT       | Time parked      |
| amount           | DECIMAL   | Amount payable   |
| status           | VARCHAR   | ACTIVE/COMPLETED |


SQL
CREATE TABLE Parking_Records (
    record_id INT AUTO_INCREMENT PRIMARY KEY,
    vehicle_id INT NOT NULL,
    slot_id INT NOT NULL,
    entry_time DATETIME NOT NULL,
    exit_time DATETIME,
    duration_minutes INT,
    amount DECIMAL(10,2),
    status VARCHAR(20) DEFAULT 'ACTIVE',

    FOREIGN KEY (vehicle_id)
        REFERENCES Vehicles(vehicle_id),

    FOREIGN KEY (slot_id)
        REFERENCES Parking_Slots(slot_id)
);

 
D. CAMERAS TABLE
| Field       | Data Type | Key |
| ----------- | --------- | --- |
| camera_id   | INT       | PK  |
| camera_name | VARCHAR   |     |
| location    | VARCHAR   |     |
| camera_type | VARCHAR   |     |
| status      | VARCHAR   |     |

SQL
CREATE TABLE Cameras (
    camera_id INT AUTO_INCREMENT PRIMARY KEY,
    camera_name VARCHAR(50),
    location VARCHAR(100),
    camera_type VARCHAR(20),
    status VARCHAR(20)
);

E. PAYMENTS TABLE
| Field          | Data Type | Key |
| -------------- | --------- | --- |
| payment_id     | INT       | PK  |
| record_id      | INT       | FK  |
| amount_paid    | DECIMAL   |     |
| payment_method | VARCHAR   |     |
| payment_status | VARCHAR   |     |
| payment_time   | DATETIME  |     |


SQL
CREATE TABLE Payments (
    payment_id INT AUTO_INCREMENT PRIMARY KEY,
    record_id INT NOT NULL,
    amount_paid DECIMAL(10,2),
    payment_method VARCHAR(30),
    payment_status VARCHAR(20),
    payment_time DATETIME DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (record_id)
        REFERENCES Parking_Records(record_id)
);
